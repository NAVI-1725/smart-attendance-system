# Student User Manual

## Overview

Students use the system to submit attendance, view attendance history, manage claims, and participate in course registration.

---

# Login

1. Open the application.
2. Enter student credentials.
3. Click Login.

---

# Device Registration

On first login:

1. Device is automatically registered.
2. Device becomes linked to the student account.

Note:

Only one device can be registered at a time.

---

# View Active Session

1. Open Home Screen.
2. View available attendance sessions.

Displayed Information:

* Course Code
* Course Name
* Faculty
* Classroom
* Session Expiry Time

---

# Mark Attendance

1. Select active session.
2. Click Mark Attendance.

The system automatically:

* Scans BLE Beacons
* Collects GPS Evidence
* Submits Attendance

Result:

Attendance status is displayed.

---

# View Attendance History

1. Open Attendance History.
2. Review previous attendance records.

Information Available:

* Course
* Date
* Status
* Claim Status

---

# Submit Attendance Claim

1. Open Attendance History.
2. Select attendance record.
3. Click Submit Claim.
4. Enter reason.
5. Submit claim.

Result:

Claim enters review process.

---

# View Claims

1. Open My Claims.
2. Review:

   * Claim Status
   * Resolution Reason
   * Decision Timestamp

---

# Course Registration

1. Open Course Registration.
2. Select Course.
3. Click Request to Join.

Result:

Registration request is sent to faculty.

---

# View Profile

Students may view:

* Student ID
* Full Name
* Email
* Registered Device

---

# Device Change Policy

If a device must be changed:

1. Contact administrator.
2. Administrator performs device unbinding.
3. Login from new device.

Result:

New device registration is completed.

---

# Student Responsibilities

* Attend sessions physically.
* Keep registered device secure.
* Submit genuine attendance claims only.
* Follow course registration procedures.

---

# Security Notes

* Proxy attendance is prohibited.
* BLE and GPS validation are enforced.
* Device sharing is not permitted.
* Attendance evidence is stored for verification.
