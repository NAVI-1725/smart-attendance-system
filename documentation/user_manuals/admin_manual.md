# Administrator User Manual

## Overview

The Administrator is responsible for managing users, courses, classrooms, enrollments, BLE beacons, and device governance within the Smart Hybrid Attendance System.

---

# Login

1. Open the application.
2. Enter administrator credentials.
3. Click Login.

---

# Create Faculty

1. Navigate to Faculty Management.
2. Click Add Faculty.
3. Enter:

   * Full Name
   * Email
   * Password
4. Click Save.

Result: Faculty account is created successfully.

---

# Create Student

1. Navigate to Student Management.
2. Click Add Student.
3. Enter:

   * Full Name
   * Email
   * Password
4. Click Save.

Result: Student account is created successfully.

---

# Create Course

1. Navigate to Course Management.
2. Click Create Course.
3. Enter:

   * Course Code
   * Course Name
4. Click Save.

Result: Course is created successfully.

---

# Assign Faculty to Course

1. Open Faculty Assignments.
2. Select Faculty.
3. Select Course.
4. Click Assign.

Result: Faculty is linked to the selected course.

---

# Enroll Student

1. Open Enrollment Management.
2. Select Student.
3. Select Course.
4. Click Enroll.

Result: Student enrollment is created.

---

# Create Classroom

1. Open Classroom Management.
2. Enter:

   * Classroom Name
   * Latitude
   * Longitude
   * Geofence Radius
3. Click Save.

Result: Classroom is created.

---

# Assign BLE Beacon

1. Open Beacon Management.
2. Select Classroom.
3. Enter Beacon UUID.
4. Click Assign.

Result: Beacon is associated with the classroom.

---

# Device Unbinding

1. Open Device Management.
2. Search for Student.
3. Select Unbind Device.
4. Confirm action.

Result: Device registration is removed.

---

# Administrative Responsibilities

* Manage Students
* Manage Faculty
* Manage Courses
* Manage Enrollments
* Manage Classrooms
* Manage BLE Beacons
* Manage Device Registrations

---

# Security Notes

* Only administrators can manage academic entities.
* Device unbinding should be performed only when necessary.
* All administrative actions are recorded in audit logs.
