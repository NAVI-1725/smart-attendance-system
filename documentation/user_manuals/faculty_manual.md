# Faculty User Manual

## Overview

Faculty members manage attendance sessions, review attendance evidence, process claims, and manage course registration requests.

---

# Login

1. Open the application.
2. Enter faculty credentials.
3. Click Login.

---

# Start Attendance Session

1. Open My Courses.
2. Select a course.
3. Click Start Session.

Result: Attendance session becomes active.

---

# Monitor Active Session

1. Navigate to Faculty Sessions.
2. View active attendance session.
3. Monitor student submissions.

---

# Review Attendance

1. Open Flagged Attendance.
2. Select an attendance record.
3. Review:

   * BLE Evidence
   * GPS Evidence
   * Student Information

---

# Confirm Attendance

1. Open attendance details.
2. Review evidence.
3. Click Confirm.

Result: Attendance status changes to CONFIRMED.

---

# Reject Attendance

1. Open attendance details.
2. Review evidence.
3. Click Reject.
4. Enter reason.

Result: Attendance status changes to REJECTED.

---

# Registration Session Management

## Start Registration

1. Open Registration Sessions.
2. Select Course.
3. Click Start Registration.

## View Requests

1. Open Active Registration Session.
2. Click View Requests.

## Approve Request

1. Select Request.
2. Click Approve.

## Reject Request

1. Select Request.
2. Click Reject.

---

# Claims Management

## Review Claim

1. Open Claims.
2. Select Claim.
3. Review attendance evidence.

## Approve Claim

1. Enter resolution notes.
2. Click Approve.

Result: Claim status becomes APPROVED.

## Reject Claim

1. Enter resolution notes.
2. Click Reject.

Result: Claim status becomes REJECTED.

---

# Export Attendance

1. Open Course Details.
2. Click Export Attendance.

Result: CSV file is generated.

---

# Faculty Responsibilities

* Conduct attendance sessions.
* Review flagged attendance.
* Process student claims.
* Manage registration requests.
* Maintain attendance accuracy.

---

# Security Notes

* Faculty can only manage assigned courses.
* All review actions are logged.
* Claims decisions are permanently recorded.
